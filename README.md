# لغة البرمجة العربية: بَيَان (Bayan) 🚀
> **"البرمجة بلغة الفكر، والابتكار بلسان عربي مبين"**

**بيان (Bayan)** هي لغة برمجة عالية المستوى، عالية الأداء، ومكتوبة بالكامل باللغة العربية. تم تصميمها لإزالة حاجز اللغة أمام المطورين والباحثين والطلاب العرب، وتوفر بيئة برمجة حديثة تجمع بين بساطة النحو العربي وقوة العمارة البرمجية المعاصرة.

## 🎯 الفلسفة والأهداف

نشأت لغة **بيان** لتقديم تجربة برمجية سلسة تعبر عن المنطق البرمجي بأسلوب عربي أصيل. 

* **الهدف الأول:** تمكين المبرمجين العرب من التفكير والبناء بلغتهم الأم دون الحاجة للترجمة الذهنية بين الإنجليزية والعربية.
* **الهدف الثاني:** بناء لغة ذات كفاءة عالية تنافس اللغات الحديثة من حيث السرعة والمرونة وإدارة الذاكرة.
* **الهدف الثالث:** توفير بيئة تعليمية ممتازة للجيل الجديد لتعلم مفاهيم خوارزميات الحاسوب بسهولة ووضوح.

## ✨ المميزات الرئيسية

* **صياغة عربية كاملة:** الدعم الكامل للحروف والرموز وعلامات الترقيم العربية (مثل الفاصلة العربية `،`).
* **نموذج كتابة متناغم:** محاذاة تلقائية للنصوص والدعم الكامل للاتجاه من اليمين إلى اليسار (RTL).
* **دعم أنماط البرمجة المختلفة:**
  * البرمجة الإجرائية (Procedural Programming).
  * البرمجة كائنية التوجه (Object-Oriented Programming).
  * البرمجة الوظيفية (Functional Programming).
* **إدارة الذكية للذاكرة:** دعم آلي لجمع النفايات (Garbage Collection).
* **أنواع البيانات الحديثة:** دعم القوائم، المعاجم، الأعداد، النصوص، والفرعيات الشجرية.

## 🔑 الكلمات المفتاحية والمفاهيم

تعبر الكلمات المفتاحية في لغة **بيان** عن معناها النحوي المباشر:

### إعلان المتغيرات والصلابة:
* `متغير`: لإعلان متغير قابل للتعديل.
* `ثابت`: لإعلان قيمة ثابتة لا تتغير أثناء التنفيذ.

### التحكم في التدفق والشروط:
* `إذا`: لبداية الشرط.
* `وإلا_إذا`: للشرط البديل.
* `وإلا`: في حال عدم تحقق الشروط.

### حلقات التكرار:
* `طالما`: حلقة تكرار مرتبطة بشرط منطقي (`while`).
* `لكل`: حلقة تكرار للمرور على القوائم والمجموعات (`for`).
* `استمر`: للانتقال للدورة التالية.
* `اخرج`: لإنهاء الحلقة فوراً.

### الدوال والمخرجات:
* `دالة`: لتعريف كتلة برمجية قابلة لإعادة الاستخدام.
* `ارجع`: لإرجاع قيمة من الدالة.
* `اعرض`: لإخراج البيانات على الشاشة.

## 💻 أمثلة برمجية

### ١. طباعة عبارة مرحباً بالعالم
```bayan
البرنامج_الرئيسي {
    اعرض("مرحباً بك في لغة بيان البرمجية!")
}
```

### ٢. الشروط المتعددة والدوال
```bayan
// دالة تقييم الدرجات
دالة تقييم_الطالب(الدرجة) {
    إذا (الدرجة >= ٩٠) {
        ارجع "ممتاز"
    } وإلا_إذا (الدرجة >= ٧٥) {
        ارجع "جيد جداً"
    } وإلا_إذا (الدرجة >= ٥٠) {
        ارجع "مقبول"
    } وإلا {
        ارجع "راسب"
    }
}

البرنامج_الرئيسي {
    متغير درجة_أحمد = ٨٥
    متغير النتيجة = تقييم_الطالب(درجة_أحمد)
    اعرض("نتيجة الطالب هي: " + النتيجة)
}
```

### ٣. حلقة التكرار القائمة على المصفوفات
```bayan
البرنامج_الرئيسي {
    متغير الأرقام = [١، ٢، ٣، ٤، ٥]
    متغير المجموع = ٠

    لكل (رقم في الأرقام) {
        المجموع = المجموع + رقم
    }

    اعرض("مجموع العناصر هو: " + المجموع)
}
```

## 🏗️ البنية التقنية (Architecture)

تعتمد لغة **بيان** على نموذج مترجم متعدد المراحل لضمان الأداء والسرعة:

```text
[المصدر العربي]  --->  [المحلل اللفظي (Lexer)] 
                      --->  [المحلل النحوي (Parser & AST)] 
                            --->  [المحاكي / الآلة الافتراضية (VM / Transpiler)]
```

1. **المحلل اللفظي (Lexer):** يفكك الشيفرة المكتوبة إلى رموز لغوية (Tokens) مع مراعاة اتجاه الحروف العربية والمحاذاة.
2. **المحلل النحوي (Parser):** ينشئ شجرة الإعراب المجردة (Abstract Syntax Tree - AST) للتأكد من المفهوم المنطقي والنحوي.
3. **محرك التنفيذ (Execution Engine):** يحول الشجرة النحوية إلى bytecode يُنفذ على آلة افتراضية فائقة السرعة، أو يترجمها لحظياً إلى لغة JavaScript/Python لسهولة التشغيل.

## 🚀 دليل البدء السريع

### المتطلبات الأساسية
* بيئة تشغيل Python 3.8+ أو Rust (يعتمد على المحرك المستخدم).
* محرر نصوص يدعم اتجاه النصوص العربية (مثل VS Code مع إضافة Bayan RTL).

### التشغيل والمُترجم
لتشغيل برنامج مكتوب بلغة بيان:

```bash
# استنساخ المستودع
git clone https://github.com/username/bayan-lang.git

# الانتقال للمجلد
cd bayan-lang

# تشغيل ملف برميجي مكتوب بلغة بيان
python bayan.py main.bayan
```
